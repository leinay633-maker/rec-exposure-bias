# 研究三的数据：KuaiRand 的视频文本和类目

研究三的语义 ID 需要视频的内容表示。KuaiRand-Pure 本身只有 `tag` 等少量视频特征，没有标题。KuaiRand 作者在 Zenodo 另发了视频标题和类目的补充文件，本文件记录它的来源、和 Pure 的对应关系和覆盖率。

§1、§2 写于 2026-11-03，跑覆盖率脚本之前。结果写在 §3 以后。

## 1. 来源

- Zenodo 记录 18159199，“Kuairand Supplementary Files: Video Captions and Categories”，2026-01-06 发布，许可证 CC BY 4.0。键是 `final_video_id`。
- 两个文件下载到 `.data/kuairand_text/`（不进 Git），大小和 md5 都和发布页一致：
  - `kuairand_video_captions.csv`：3,222,932,768 字节，md5 `9fd4e7587ffd0c8dc289d013858fb229`；列 `final_video_id, caption, show_cover_text, duration`。
  - `kuairand_video_categories.csv`：3,687,928,520 字节，md5 `8a4c772d3d8f8cf65fa1e1eb896f4177`；四级类目，每级有编号、名称和概率，缺失记作 `-124` / `UNKNOWN`。
- 文件覆盖整个 KuaiRand（27K 版的全部视频），比 Pure 的 7,583 个视频多得多。

## 2. 要核对的

- **编号对应**：看 `final_video_id` 是否就是 Pure 的 `video_id`。Pure 的 `video_features_basic_pure.csv` 有 `video_duration` 和 `tag`，逐个视频比：
  - 补充文件的 `duration` 和 `video_duration` 相等的比例（两边都有值的视频）。这一项在 99% 以上才算对上，否则停下，不用这份文本。
  - `tag` 有 1,791 个视频是逗号分隔的多个编号、96 个缺失，所以类目只作旁证：报告 `first_level_category_id` 落在该视频 `tag` 里的比例，以及等于第一个 `tag` 的比例，不设门槛。
- **覆盖率**：Pure 的 7,583 个视频里，标题文件和类目文件各有多少个；重复的编号；标题为空（缺失或去掉空白后为空）的比例；只有话题标签、去掉 `#…` 和 `@…` 后为空的比例；标题长度（字符）的分布；`show_cover_text` 非空的比例；每一级类目是 `UNKNOWN` 的比例和一级类目的个数。
- **格式坏行**（第一次运行后补，写在重跑之前）：第一次运行 `20261103-205904-rlrec-text-coverage-e7c15a`发现标题文件有约 0.4% 的行格式坏了，标题里的逗号或换行把文字挤进了 `duration` 列，pandas 因此把整列读成字符串，时长比较全部判成不等，那次的“编号对应”结论作废。重跑时 `duration` 按数值解析，解析不出数的行记为坏行：报告 Pure 里坏行的个数和编号，坏行的标题不算可用，时长比较只用解析出数的行。
- **采集时点**：补充文件发布于 2026 年，日志在 2022 年 4–5 月。标题可能在日志之后被作者改过，这一点没法从文件本身核实，只记成风险。
- **怎么跑**：`scripts/kuairand_text_coverage.py`，分块读两个大文件，只留 Pure 的视频；登记在 `.runs/rlrec/registry.jsonl`，输出 `.runs/rlrec/text-coverage/<运行编号>/coverage.json`，复制进 `evidence/rlrec/`。下载的文件当作不可信数据：脚本放在数据目录之外，用 `python -I` 运行，路径作参数传入。
- **用不用的标准**：编号对上、标题非空的视频不少于 95% 时，研究三的语义 ID 用标题加类目名的文本表示；不到 95% 时，改用冻结的召回双塔的视频向量加类目，在研究三协议里定。

## 3. 结果（运行 `20261103-210237-rlrec-text-coverage-e4314e`，2026-11-03）

- **文件**：两个文件各 32,038,725 行，md5 和发布页一致。编号单调递增、没有重复。
- **编号对应**：Pure 的 7,583 个视频在两个文件里都在。两边都有时长的 7,263 个视频，时长全部相等，`final_video_id` 就是 Pure 的 `video_id`。一级类目落在该视频 `tag` 里的占 78.2%，等于第一个 `tag` 的占 75.2%（旁证，不设门槛）。
- **标题**：
  - 格式坏行 35 个（编号见 JSON 的 `malformed_ids`），标题不可用；标题为空 85 个。可用标题 7,463 个，占 98.4%。
  - 去掉 `#…` 和 `@…` 后为空的 610 个（8.0%，含上面 85 个空标题）；只剩话题标签的仍算可用。
  - 可用标题的长度（字符）均值 42，P10 16、P50 37、P90 73，最长 856。
  - `show_cover_text` 非空的 944 个（12.4%）。
- **类目**：一级类目有值的 7,571 个（99.8%，38 种），二级 6,493 个（85.6%，155 种），三级 2,849 个（37.6%，245 种），四级 527 个（6.9%，77 种）。有值时概率的中位数都在 0.97 以上。
- **判定**：编号对上，可用标题 98.4% 不少于 95%。研究三的语义 ID 用标题加类目名的文本表示；35 个坏行和 85 个空标题的视频只用类目名。
- **第一次运行** `20261103-205904-rlrec-text-coverage-e7c15a` 的时长比较因坏行全部判成不等，结论作废，输出留在 `.runs/` 和 `evidence/` 里备查。
- **风险**：标题和类目是 2026 年发布的，可能和 2022 年日志期间的不完全一样；类目是模型预测的（有概率），不是人工标注。
