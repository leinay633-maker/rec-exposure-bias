# 研究三的可行性审计

研究三准备检验：给语义 ID 生成式推荐做 RL 后训练时，用随机曝光校准过的奖励，能不能让策略在随机曝光上的价值更高。写协议之前，先估随机曝光评价的精度、看倾向分和奖励模型的家底。

本文件 §1–§3 写于 2026-11-03，跑之前。只用 KuaiRand-Pure 的训练窗口和随机校准集（4/22–4/28，tab 1），不读两份测试集的标签。结果写在 §4 以后。

## 1. 随机曝光评价的精度

- **替身策略**：研究一冻结模型组的 4 个召回模型（热度、ItemCF、双塔、logQ 双塔；两个双塔各 3 个种子）。每个模型对每个用户在全池 7,583 个视频里去掉训练期看过的，按 `retrieval.recall_ndcg` 的方式稳定排序。策略是“前 K 个里均匀推一个”，K = 10、50、100、200、500。
- **评价行**：随机校准集的留出段 4/26–4/28（研究三准备用来选模型的那段），tab 1，去掉该用户训练期看过的视频。人群是至少有一行可评价行的用户。
- **估计量**：
  - 名义均匀倾向：SNIPS 等于落入前 K 个的行里 is_click 的比例，跨用户按行合并（同研究一协议 §20）。
  - 估计倾向：q_i = (n_i + 1) / (Σ_j n_j + 7,583)，n_i 是视频 i 在 4/22–4/25 随机日志（tab 1）里的行数。每行权重 w = π(i|u) / q_i，SNIPS = Σ w·click / Σ w。
  - 每个策略报告点估计、用户 bootstrap（10,000 次，种子 0）的 95% 区间和标准误、落入行数，以及有效样本量 ESS = (Σ w)² / Σ w²（名义倾向下就是落入行数）。双塔逐种子报告，另报三个种子把每人的计数先平均后的值（同研究一 §20）。
- **两两差的精度**：
  - 大差：logQ 双塔 − 双塔，同种子配对；
  - 近零差：同一模型的两个种子之差（双塔种子 0 − 种子 1，logQ 双塔种子 0 − 种子 1）。研究三比较的是同一 SFT 起点、相同 KL 下的策略，彼此重合得多，近零差的标准误更接近研究三的情形；
  - 每对报告差的标准误，以及两份前 K 的人均重合率。
- **外推到随机测试**：随机测试 4/29–5/08 的 tab 1 有 892,896 行、全部 tab 共 26,907 个用户（`docs/DATA.md` §2、§4，审计时只数了元数据）。按“标准误与行数的平方根成反比”和“与用户数的平方根成反比”各外推一次。最小可检出差 = `stats.mde_multipliers(3)[0]` × 外推的标准误，即 3 个主假设 Holm 第一步、功效 0.8。测试期每人的行数比留出段多，按用户聚类的方差不一定随行数缩小，所以两种外推都报，以大的那个为准。
- **闸门**：实际意义门槛定为策略价值相对差 5%，基准是 logQ 双塔前 100 在留出段上的名义 SNIPS（三个种子的计数先平均）。K = 100 时，近零差在名义倾向下外推的最小可检出差（取两种外推里大的那个）低于门槛，才进研究三的主实验；否则先换 K、换 long_view 或换评价口径再估，不硬上。

## 2. 倾向分

- 随机日志（tab 1）每个视频的行数分布：4/22–4/25 和 4/26–4/28 各报均值、P01、P10、P90 和变异系数，以及两段每视频行数的 Pearson 相关。
- 名义均匀和估计倾向两种 SNIPS 之差，按模型和 K 报告。差别大的话，研究三把估计倾向列为敏感性分析。

## 3. 奖励模型清点（不跑）

- 研究一协议 §17 的 A 就是冻结模型组的 3 个 LightGBM，文件和 sha256 在 `configs/zoo_manifest.json` 里。
- §18 的 B 常规、B 随机当时在内存里训练，没有存模型文件。§18 的“A 重训”和 A 在两份测试集上预测的最大绝对差都是 0（`.runs/ablation/20261101-165659-ablation-random-mix-fixed-29339e/random_mix_fixed.json` 的 `refit_max_abs_prediction_diff`），所以按 §18 的设置重训可以逐位复现。研究三实现时重训 B 常规、B 随机并存档，先用 §18 输出里的 UAUC 核对，对不上就停下。

## 5. 结果（运行 `20261103-195125-rlrec-feasibility-042b36`，2026-11-03）

- **人群**：留出段 tab 1 共 123,555 行、14,261 人。去掉训练期看过的 58 行、训练期没有行的用户的 2,184 行，剩 13,911 人、121,313 行。
- **单个策略**（K = 100，名义倾向）：热度 0.295（标准误 0.012，落入 1,574 行），ItemCF 0.327（0.013，1,515 行），双塔三个种子平均 0.269（0.009，1,533 行），logQ 双塔三个种子平均 0.357（0.012，1,465 行）。每个 K、每个种子的值和区间见 JSON 的 `policies`。
- **两两差的精度**（K = 100，名义倾向，外推到随机测试）：

  | 对 | 差 | 留出段标准误 | 前 100 重合率 | 最小可检出差（按行 / 按用户） |
  | --- | --- | --- | --- | --- |
  | 双塔种子 0 − 种子 1（近零） | +0.0085 | 0.0116 | 48.9% | 0.0139 / 0.0271 |
  | logQ 双塔种子 0 − 种子 1（近零） | +0.0029 | 0.0098 | 70.2% | 0.0116 / 0.0227 |
  | logQ 双塔 − 双塔（同种子，大差） | +0.082 – +0.095 | 0.0147–0.0148 | 21.7%–21.9% | 0.0175–0.0177 / 0.0341–0.0345 |

  外推系数按行是 0.369（121,313 / 892,896 开方），按用户是 0.719（13,911 / 26,907 开方）；最小可检出差的乘数是 3.236（3 个主假设 Holm 第一步、功效 0.8）。大差在哪种外推下都远大于最小可检出差。
- **闸门**（§1）：基准是 logQ 双塔前 100 的名义 SNIPS 0.357，门槛是它的 5% 即 0.0179。近零差里最差的是双塔那对，按用户外推的最小可检出差 0.0271，**高于门槛，闸门没过**。其他 K 下（同样取两种外推里大的那个，门槛按各自 K 的基准算）：

  | K | 最差的近零最小可检出差 | 门槛 | 过不过 |
  | --- | --- | --- | --- |
  | 10 | 0.1026 | 0.0197 | 不过 |
  | 50 | 0.0393 | 0.0187 | 不过 |
  | 100 | 0.0271 | 0.0179 | 不过 |
  | 200 | 0.0170 | 0.0173 | 勉强过 |
  | 500 | 0.0094 | 0.0156 | 过 |

- **两种外推哪个更贴近**（描述，不改闸门的判定）：留出段上，单个策略的用户 bootstrap 方差和按行二项方差之比（设计效应）在 K = 100 时是 1.01–1.09，每人落进前 100 的行平均只有 0.10–0.11 行，用户内聚集几乎没有，按行外推更贴近；K = 500 时设计效应升到 1.36–1.53。测试期每人的行数约是留出段的 3.8 倍，聚集会变强，所以真实的最小可检出差在两种外推之间。按行外推的话 K = 100 也能过（0.0139 < 0.0179），但闸门事先定的是取大的那个，判定照旧是不过。
- **倾向分**（§2）：
  - 每视频行数：4/22–4/25 均值 21.3、P01 1、P10 15、P90 28、变异系数 0.252，72 个视频一行都没有；4/26–4/28 均值 16.3、P01 0、P10 11、P90 22、变异系数 0.297。两段的 Pearson 相关只有 0.239。
  - 纯泊松抽样的变异系数会是 0.217 和 0.248，所以每视频行数的差别大半是抽样噪声，跨时间稳定的那部分不多。按 4 天的计数估倾向，噪声比要纠的偏差还大。
  - 估计倾向和名义倾向的 SNIPS 之差，全部模型、全部 K 都在 ±0.012 以内（K = 100 时在 −0.008 到 +0.004），都小于一个标准误；K = 100 时估计倾向的有效样本量只有落入行数的 66%–94%。
- **奖励模型**（§3）：没跑，清点结论同 §3。

## 6. 结论和对研究三的影响

- 按事先定的闸门，“前 100 个里均匀推一个”这类集中的策略，随机测试分不出 5% 的相对差，研究三不拿它当主指标。
- K = 500 在两种外推下都过，K = 200 勉强过。研究三协议的主指标定成策略前 500 个视频的列表价值（前 500 个里均匀推一个，名义倾向 SNIPS），K = 100、200 和策略本身按概率抽样的价值作次要指标；后者同时报告有效支撑 1/Σπ²，它小于 500 时不拿来下结论。
- 近零差用的是召回模型的两个种子，前 100 只重合 49%–70%。研究三比较的是同一个 SFT 起点、相同 KL 下的策略，重合多少要等 SFT 训出来才知道。研究三冻结前，在留出段上用真实的候选策略再估一次最小可检出差，过不了就加大 K 或减少主假设个数，不改门槛。
- 名义倾向作主估计，估计倾向作敏感性分析。估计倾向噪声大，研究三如果要用，先在 4/22–4/25 上做收缩（例如向均匀倾向收缩），收缩的强度在协议里事先定。
- 外推用的 26,907 是随机测试全部 tab 的用户数。随机日志 99% 以上在 tab 1，但研究三的人群还要求有训练期历史，按留出段的比例（13,911 / 14,261）大约少 2.5%，标准误相应大约大 1%，不改变上表的判定。
