# 研究二数据审计：KuaiRec 2.0

审计运行 `20261101-150653-audit-9a0516`（`python -m genrec.audit`），输出 `.runs/kuairec/audit/20261101-150653-audit-9a0516/audit.json`，副本放进 `evidence/kuairec/`。小矩阵是封存的稠密测试，审计只读了它的用户、视频、日期和时间戳列。大矩阵整份读进过内存，但只汇总了训练窗口的标签，8/27–9/05 的标签没有汇总或输出（协议 §1）。

## 1. 来源与校验

- zenodo 记录 18164998 的 `KuaiRec.zip`，431,964,858 字节，md5 `261550d472c48eff4990fb13c0e5bcf7`，和 zenodo 记录一致。只解压了 `data/` 下的 CSV，没有运行包里的脚本。
- 许可：CC BY-SA 4.0。仓库只放获取方式、清单和哈希，不转发数据文件。
- 视频文本 `kuairec_caption_category.csv`（2024-06-02 加入）的 md5 `31bc38cd…` 和 zenodo 记录一致。有 4 条记录的标题里带未加引号的换行，读成“3 个字段 + 8 个字段”两行；`genrec/text.py` 把它们拼回，拼后 10,728 个视频各一行、没有重复。

## 2. 总数和时间

| | 行数 | 用户 | 视频 | 日期 |
| --- | --- | --- | --- | --- |
| 大矩阵 | 12,530,806 | 7,176 | 10,728 | 2020-07-05 至 09-05 |
| 小矩阵 | 4,676,570 | 1,411 | 3,327 | 2020-07-05 至 09-05 |

- 都和 README 一致。
- 大矩阵只在 28 天里有数据：7/05–7/12、8/01–8/10、8/27–9/05，中间两段空着。
- 小矩阵 63 天每天都有，181,992 行（3.9%）没有日期和时间戳。它的采集时段和大矩阵整段重叠，所以稠密测试不是“训练之后的时间”，而是同期。

## 3. 大矩阵和小矩阵的关系

- 小矩阵的 1,411 个用户、3,327 个视频全都在大矩阵里。
- 大矩阵里“小矩阵用户 × 小矩阵视频”的交互是 0 行：这些（用户，视频）对只在小矩阵里。
- 所以小矩阵用户在大矩阵里的 571,061 行全是候选池以外的视频；大矩阵里候选池视频的 10,272,525 行全来自其他 5,765 个用户。
- 结果：稠密测试的用户在训练里没有候选池视频的历史；“同一批用户、同一个候选池”的有偏测试没法从大矩阵里取，只能在小矩阵上按曝光量构造（协议 §2.2）。
- 小矩阵每个用户的（用户，视频）对中位数 3,315 个（P10 3,304），接近 3,327。

## 4. 去重

- 大矩阵整行完全相同的有 965,819 行，去掉后，（用户、视频、时间戳）相同但其他列不同的还剩 4,353 行，按研究一的规则整组删掉，剩 11,560,634 行。
- 小矩阵没有重复。

## 5. 训练窗口的标签（只在 7/05–8/26 汇总）

- 训练窗口 8,571,929 行（实际是 7/05–7/12 和 8/01–8/10），7,174 个用户；8/27–9/05 有 2,988,705 行、6,988 个用户，协议里分成验证（8/27–8/31）和封存的自然测试（9/01–9/05）。审计跑的时候训练窗口写的是 7/05–8/26，8/11–8/26 没有数据，和协议的 7/05–8/10 是同一批行。
- `watch_ratio`（播放时长 / 视频时长）中位数 0.74，P90 1.79，P99 4.80。
- 正样本率：大于 0.5 是 64.8%，大于 1.0 是 34.4%，大于 2.0 是 7.5%。按 README 给的“喜欢”例子取大于 2.0，训练窗口有 644,725 条正样本，其中 512,584 条在候选池视频上。
- 小矩阵用户里 1,401 人在训练窗口有至少一条正样本，每人中位数 18 条（P10 6 条）；其他用户中位数 83 条。

## 6. 候选池视频的曝光（训练窗口，其他用户）

- 3,327 个候选池视频里有 555 个在训练窗口一次曝光都没有，只能靠文本学到；其余视频的曝光数中位数 2,224。
- 最热的两成视频占曝光的 38.6%，比研究一的随机曝光对照温和得多（KuaiRand 常规测试 72.8% 的行落在最热两成上）。
- 每个其他用户在训练窗口看过的候选池视频数，中位数 1,202 个（占候选池 36.1%），P10 471 个、P90 1,699 个。

## 7. 视频文本

- 10,728 个视频里 9,372 个有标题，4,033 个有人工封面文字，10,688 个有类目，10,724 个至少有一种文本。
- 候选池 3,327 个视频里 3,169 个有标题，3,326 个至少有一种文本。
- 文本只有内容，没有说明采集时间；标题和类目可能是数据发布时的版本，作为已声明的风险，见协议 §1.2。

## 8. 对设计的影响

- 稠密测试的用户在训练数据里没有候选池视频，“同一批用户、同一个候选池”的有偏测试只能在小矩阵上按曝光量构造（协议 §2.2）。
- 曝光的热度偏向比研究一温和（最热两成占 38.6%），有偏测试和稠密测试的差别可能比研究一小。
- 555 个零曝光视频单列为冷门组（协议 §2）。
- 具体的切分、标签和抽样以 `docs/kuairec/PROTOCOL.md` 为准。
